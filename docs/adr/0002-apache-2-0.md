# 2. Apache-2.0

## Context

This package's reporter is based on a reporter written for Stryker, which is licensed Apache-2.0. Part of this package's code follows Stryker's own reporter as a template. Two of its functions are close copies of the corresponding functions in Stryker.

## Decision

License this package Apache-2.0.

This matches the license of the code it is based on. It also removes a license mismatch as an obstacle if this reporter later becomes a pull request to Stryker itself.

## Consequences

Any code added later that is not based on Stryker's own code still carries the same license, Apache-2.0, for the whole package.
